# テンプレート

これはヘッダーとフッターのテンプレートページです。
使用する場合は`template/index.md`のフロントマターの`title`と`description`を変更してください。
\\(\KaTeX\\)数式は、本文に`$$`や`\(...\)`などの区切り文字を含めるだけで自動的に有効になります。
目次を挿入する場合は、挿入したい位置に`## 目次`という見出しを追加してください。
